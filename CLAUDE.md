# Two Fakto projects

- `demo/`: Tostr, a fake smart-toaster company with 31 facts and the website, docs, SDK, decks
  and box copy that state them. Use it to see Fakto work.
- `boilerplate/`: the same setup with no facts and empty folders. Use it to start your own.

Work inside one of them: run every command from that folder and follow its CLAUDE.md. Start
of a session: ask which one (unless the user said), `npm install` there if `node_modules` is
missing, then start its canvas with its `fakto-canvas` skill and tell the user the address.
