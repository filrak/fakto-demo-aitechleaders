# House rules

Claude reads this file before it rewrites any line. Replace the examples with your own.

## Voice

- Write in plain, direct sentences. Say what the reader gets, not how the feature works.
- Use the product names exactly as written in the facts.

## Words

- Preferred: "customers", "plan".
- Avoid: "users" in marketing copy, "cheap".

## Never

- Never round a number up.
- Never state a fact that has no record in `facts/`.
